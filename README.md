 В данном репозитории реализовано небольшое приложение-мессенджер на React.

Функционал Messenger:

Список пользователей и чатов
Открытие отдельного диалога с пользователем
Отображение сообщений выбранного пользователя
Отправка собственных сообщений
Разделение сообщений пользователя и собеседника
Сохранение сообщений в LocalStorage (Данные сохраняются после перезагрузки страницы)
Прокрутка области сообщений при большом количестве сообщений


Используемые технологии:

React
JavaScript (ES6+)
CSS3
React Router
React Hooks (useState, useEffect)
LocalStorage
